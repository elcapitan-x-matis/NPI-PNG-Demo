System Overview

A fully-fledged institutional management platform built for the National Polytechnical Institute of Papua New Guinea.

The NPIPNG Learning & Academic Management System is a complete, role-based web application designed to digitize the operations of the institute. It consolidates three previously fragmented workflows into one unified ecosystem:

1. Teaching & Learning

Course delivery, assessments, submissions, and live GPA tracking.

2. Administration

Student registration, academic records, transcript generation, and certificates.

3. Accommodation

Dormitory management, room allocation, and student occupancy tracking.

Core Features

Built to solve real institutional challenges at NPIPNG.

Role-Based Access Control

Strict separation between Students, Instructors, Registrars, Academic Admin, Student Services, and Superusers.

Dynamic GPA Engine

Real-time weighted grading calculations that automatically update a student's cumulative GPA and transcript.

Accommodation Manager

Gender-matched room allocation with live occupancy tracking to prevent overbooking.

Automated Transcripts

One-click generation of official academic transcripts with locked-in semester and cumulative GPAs.

File Submissions

Students can upload assignments securely, while instructors grade them and provide feedback in real-time.

Responsive UI

Built with a custom flat-design theme, optimized for both desktop and mobile devices.

System Architecture

Custom MVC Architecture with a JSON-Powered Demo deployment.

1. Browser Request (HTML5, CSS3, Bootstrap 5)
2. Client-Side Routing (JavaScript / jQuery)
3. Data Layer (data.json mock database)
4. Dynamic DOM Rendering (Vanilla JS Templates)
Technology Stack
PHP 8.1 (Original) Custom MVC MySQL / MariaDB HTML5 CSS3 Bootstrap 4 / 5 JavaScript (ES6+) jQuery JSON
